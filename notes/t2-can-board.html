t2-can-board

2026-08-15 · Tesla / CAN

LILYGO T2-CAN ESP32-S3에서 도는 Tesla HW3 듀얼 CAN 펌웨어다. 저장소는 alzza/t2-can-board. 개인 실험용이다. CAN 송신은 정차 후 수신과 BUS-OFF를 확인한 뒤에만 켠다.

채널

CAN-A는 MCP2515 (CS 10). Summon Unlock과 TSLLC. CAN-B는 ESP32 TWAI (TX 7, RX 6). Nag Killer. Wi-Fi AP TeslaCAN 에서 Web UI와 OTA.

차량 버스는 이미 종단되어 있다. 보드 쪽 120 Ω 은 빼야 한다.

빌드

sh 
git clone https://github.com/alzza/t2-can-board.git
cd t2-can-board
pio run -e lilygo_t2can
pio run -e lilygo_t2can -t upload

HW3 비트

ID 0x3FD mux 1. bit 19는 ECE R79 해제, bit 46은 Summon 제한 해제. 기본 빌드는 HW3이라 bit 46만 쓴다. Nag는 CAN-B ID 880을 조건에 맞게 다시 보낸다.

수신 게이트 발췌

저장소 nag_kill_test_x1.cpp 의 앞부분. DAS 921을 보고 EPAS 880만 조건 주입한다.

cpp 
void handleMessage(CanFrame &frame, CanDriver &driver) override
{
    if (frame.id == 921) {
        if (frame.dlc >= 6)
            dasHandsOnState = (frame.data[5] >> 2) & 0x0F;
        return;
    }

    if (frame.id != 880 || frame.dlc < 8)
        return;

    uint8_t handsOn = (frame.data[4] >> 6) & 0x03;
    if (!nagKillerActive || handsOn != 0)
        return;

    uint8_t dasState = dasHandsOnState;
    // 0 = NOT_REQD, 8 = SUSPENDED: no echo
    if (dasState == 0 || dasState == 8)
        return;
}
