BR, LM 조작 버튼을 화면에 넣는 순서

이 순서는 PC용 InTouch에 BR과 LM 조작 버튼을 붙이는 작업이다. PLC 프로그램은 손대지 않는다. PLC 태그는 이미 컨트롤러에 있다. InTouch 태그 사전에 같은 Item이 있으면 그 태그를 그대로 버튼에 연결한다.

1. 접속 이름 확인 2. 태그 확인 3. BR 화면 4. LM 화면 5. 확인

1. 접속 이름 확인

  1. WindowMaker를 연다. 감시 중인 WindowViewer가 아니다.
  2. 위 메뉴 Special에서 Tagname Dictionary를 연다.
  3. 찾기 칸에 dHMI_Rep를 입력하고, 화면에서 값이 실제로 바뀌는 태그를 연다.
  4. Access Name에 적힌 이름을 적는다. 새 태그를 만들 때도 이 이름을 목록에서 고른다. 키보드로 비슷하게 치지 않는다.
  5. Item 칸을 본다. dHMI_Rep[51]처럼 태그 이름만 있으면 접두는 없다. [L1_APM]처럼 대괄호가 앞에 붙어 있으면 그 접두를 같이 적는다.

2. 태그 확인

태그 사전 찾기 칸에 아래 Item을 넣는다. 같은 Item이 나오면 그 Tagname을 버튼에 쓴다. 새로 만들지 않는다.

검색 결과가 없을 때만 New로 추가한다. Type은 I/O Discrete로 둔다. Memory Discrete는 화면 안에서만 도는 태그이므로 고르지 않는다. Access Name은 1번에서 확인한 이름을 고르고, 읽기와 쓰기를 모두 켠다. Item에는 표의 오른쪽 글자를 넣는다. 1번에서 접두를 적어 두었으면 그 접두를 Item 앞에 붙인다. 따옴표와 빈칸은 넣지 않는다.

3. BR 화면

BR 감시 창을 연다. 버튼 여섯 개의 글자를 수동, 자동, 리프트 상승, 리프트 하강, 정렬 전진, 정렬 후진으로 적는다.

수동, 자동

  1. Wizard에서 Momentary Pushbutton을 고른다. Toggle은 고르지 않는다.
  2. 수동 버튼을 화면에 놓고 두 번 누른다.
  3. 터치 태그에 BR_ModeMan을 넣는다. 마우스 버튼을 누르고 있는 동안 1, 떼면 0이 되게 둔다.
  4. 같은 버튼에서 Fill Color의 Discrete를 연다. 태그는 BR_ManLamp로 두고, 0은 회색, 1은 초록으로 지정한다.
  5. 자동 버튼도 같은 종류로 만든다. 터치 태그는 BR_ModeAuto, 색 태그는 BR_AutoLamp다.

리프트, 정렬

  1. 네 버튼 모두 Momentary Pushbutton으로 만든다.
  2. 리프트 상승은 터치에 BR_LiftUp을 넣는다. 색은 Discrete Expression에 BR_UpOut OR BR_UpSens를 넣는다. 0은 회색, 1은 초록이다. 출력이 나가 있을 때와 상승 센서가 들어와 있을 때 둘 다 초록이다.
  3. 리프트 하강은 터치 BR_LiftDown, 색은 BR_DnOut OR BR_DnSens다.
  4. 정렬 전진은 터치 BR_AlignFwd, 색 BR_FwdOut이다.
  5. 정렬 후진은 터치 BR_AlignBwd, 색 BR_BwdOut이다.

저장한 뒤 Runtime으로 전환한다. 수동을 한 번 누르면 버튼이 초록으로 유지된다. 다시 수동인 상태에서 리프트 상승을 누르는 동안 그 버튼이 초록이면 연결은 된 것이다. 상승 센서가 들어오기 전에는 손을 떼도 초록이 남을 수 있다. 하강을 누르면 상승 색은 꺼진다.

4. LM완료

dCA[5].WorkOk_LM은 모드 조건이 없다. CA가 자동이어도, LM이 자동이어도, 수동이어도 1과 0이 들어간다. LM을 수동으로 바꾼 뒤에 누를 필요는 없다.

  1. 사각형 버튼 두 개를 그리고 글자를 ON, OFF로 적는다. Momentary Pushbutton으로 만들지 않는다.
  2. ON 버튼을 두 번 누르고 Touch Links의 Action을 연다.
  3. On Left Click에 LM_WorkOk = 1; 한 줄만 넣는다.
  4. OFF 버튼의 On Left Click에는 LM_WorkOk = 0; 한 줄만 넣는다.
  5. ON 버튼 Fill Color의 Discrete 태그는 LM_WorkOk다. 1이면 초록, 0이면 회색이다.
  6. OFF 버튼 Fill Color도 LM_WorkOk다. 0이면 초록, 1이면 회색이다.

ON을 한 번 누르면 1이 남고, OFF를 한 번 누르면 0이 남는다. 버튼을 누르고 있는 동안에만 1을 유지하게 만들지 않는다. 이 비트가 1이고 LM이 홈이면 대차는 zCA_LM_Ok로 LM을 통과시킨다. 돌아가는 밀링을 바로 세우지는 않는다.

Runtime에서 ON을 한 번 누른다. ON이 초록으로 남고 OFF가 회색이면 된다. OFF를 한 번 누르면 색이 바뀌고, PLC의 dCA[5].WorkOk_LM도 같이 0이 되면 된다.

5. 확인

  1. Runtime에서 BR 수동을 누른다. PLC의 cBR.Mode_Man이 1이 된다.
  2. BR 자동을 누른다. cBR.Mode_Auto가 1이 되고 cBR.Mode_Man은 0이 된다.
  3. 다시 수동으로 두고 리프트 상승을 누른다. 누르는 동안 uBRLI.ui_UP_PB가 1이다. 유압과 비상, 안전 조건이 맞으면 q_BRLIUP이 1이 된다.
  4. LM완료 ON을 누른다. 모드를 바꾸지 않아도 dCA[5].WorkOk_LM이 1로 남는다. OFF를 누르면 0으로 남는다.
화면에서 보이는 상태고치는 곳
버튼을 눌러도 PLC 값이 안 바뀐다Access Name을 1번의 감시 태그와 같게 다시 고른다. Item 철자를 표와 맞추고, 쓰기가 꺼져 있으면 켠다.
수동을 누른 직후 색이 바로 회색이 된다버튼 색을 BR_ManLamp 또는 LM_ManLamp에 연결한다. ui_Mode 태그에는 색을 연결하지 않는다.
Item 저장이 거절된다기존 감시 태그 Item 앞에 있던 접두를 새 Item 앞에도 붙인다.
태그는 1인데 실린더가 안 움직인다BR을 수동으로 둔다. cBR.zEnable이 1인지 확인한다. 비상정지나 고장이 있으면 버튼 값이 맞아도 출력은 나가지 않는다.
