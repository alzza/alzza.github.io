# 전해정련 모델 시험에 필요한 정보

기준일: 2026-10-25. 기준 문서: [전해정련 연구계획서](https://alzza.github.io/notes/electrorefining-attention.html). 연구의 주축은 **Cheng → Liu**, 시간 이력 비교는 **Correa**로 둔다. 이는 사용자가 정한 연구 비중이며 논문 성능의 순위가 아니다. 1순위 정답은 전류효율, 2순위 정답은 Vision S등급률이다.

Cheng의 출구 Cu·As 모델은 조건 해석·물질수지·트리 기준의 근거이고, Liu는 물리 관계와 여러 출력의 공동 학습을 검토할 근거다. 아래 표에는 논문에 명시된 항목과 우리 공장의 연결·검증을 위해 추가한 항목이 함께 있다. Cheng 전문·Table S1은 미확보이고 Liu의 물리 제약·출력 표기·무작위 소표본 평가에는 확인할 부분이 남아 있다. 같은 이름의 입력이라도 측정 대상과 단위가 같아야 대응시킨다.

## 먼저 받을 자료

수집 간격은 **실제 저장된 원본 주기**를 우선한다. 합성 시험의 2시간 간격은 회사의 수집 기준이나 논문 재현의 증거가 아니다. 모든 분석·센서·작업 행에는 아래 공통 필드를 붙인다.

`record_id, source_system, section_id, cell_or_circuit_scope, cycle_id, sample_or_event_at, available_at, value, unit, measurement_location, quality_flag, revision_id`

`sample_or_event_at`은 실제 채취·측정·사건 시각이고 `available_at`은 결과를 연구·조업에서 처음 이용할 수 있었던 시각이다. 시각대(KST/UTC)와 수정 이력을 함께 보존한다. 분석일만 있고 공개 시각이 없으면 초기 예측 이용 여부를 확정할 수 없다.

## 시험을 시작할 최소 묶음

1. 한 Section의 약 3주 기록으로 조동→통단전→인양→Vision을 연결하고, 효율·순중량이 실제 어느 범위의 정답인지 확인한다. 동일 계통 효율 한 값을 여러 Section의 독립 정답으로 늘리지 않는다.
2. 승인된 수개월 자료에서 독립 작업/조동 lot/공유 계통 묶음 수, 누락·지연·저품질/단락 사건 수를 센다. 행 수만으로 충분성을 판단하지 않는다. 공유 헤드탱크·정류기·조동 lot와 Section 동/서는 종속 묶음으로 기록하고 독립 캠페인 수를 별도로 센다. 합성 모델의 Cell-Cycle은 실제 Section의 Cell 수를 곱해 만든 표본이 아니다. 계절 가설에는 연중 범위와 반복 계절이 추가로 필요할 수 있다.
3. 24·48·72·96·120·144·168시간 시점별로 당시 공개된 값만 넣는다. 168시간이 실제 종료 시점이면 이를 조기경보로 부르지 않는다. 실제 Cycle이 더 짧으면 종료 뒤 시점을 생성하지 않는다.
4. 미래 기간을 고정하고, 학습 정답이 공개되기 전 시점으로 거슬러 학습하지 않는다. 같은 작업/공유 묶음의 여러 시점은 함께 배정하고 경계의 늦게 완료된 작업은 제외한다.
5. 1순위 효율 MAE/RMSE(%p), 2순위 S등급률 MAE/RMSE(%p)를 보고한다. 출구 Cu·As(g/L), 조건부 석출량(kg), 경보 사건 지표는 별도로 보고한다.

## 현재 합성 모델 시험의 의미

별도 `synthetic_model_v1/`의 생성기·모델·평가는 위 연결과 시간 제한을 소프트웨어로 실행하는 시험이다. 만들어진 데이터가 현장을 대표하거나 논문 원자료를 재현하지 않는다. 합성식의 온도·첨가제 계수와 기준값은 현장 권장값이 아니다. 결과가 좋아도 실제 성능·원인·최적 투입·경보 선행시간을 확인한 것은 아니다.
